# CYSCUVU Website Guidelines

## Purpose

- This website serves the Cybersecurity Club at Utah Valley University.
- It is a testing and learning environment for club members.
- It holds useful information and resources for members pursuing cybersecurity.

## Development Principles

- Keep the website and its code simple.
- Prefer straightforward HTML and Tailwind CSS over unnecessary abstractions.
- Write clean, readable code that club members can easily understand and edit.
- Use comments sparingly and only when they clarify something that is not obvious.
- Keep the design focused and avoid unnecessary dependencies or complexity.
