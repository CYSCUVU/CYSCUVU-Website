# How-To
This site was built using tailwindcss for its CSS (obviously). In order to implement it on your machine, go ahead and download tailwind using the method that best suits you. Tailwind is available on most distro packages, and has it's own executable.
To use it:
1. First, clone this repo.
2. Then, from within the repo, run the following command. `tailwindcss -i input.css -o output.css --watch`. The `--watch` signal keeps tailwind running so that you can continuously make changes to the page and it'll render them in the CSS.
3. ***Create the greatest website this planet has ever seen!***
