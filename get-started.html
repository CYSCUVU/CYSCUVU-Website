New member guide

Start here

You do not need prior cybersecurity experience. Show up, ask questions, and learn with the club.

  1. 01

    Join Discord

    Announcements, meeting details, project discussion, and help from other members live here.

    Join CYSCUVU →
  2. 02

    Set up a learning environment

    Start with a computer, a modern browser, and a terminal. Use hosted labs until you are comfortable managing a virtual machine.

  3. 03

    Learn Linux and networking basics

    Practice navigating files, using SSH, reading IP addresses, and understanding common protocols.

  4. 04

    Complete your first challenge

    Try picoCTF or the OverTheWire Bandit wargame. Take notes on what worked and what you had to look up.

    Choose a practice site →
  5. 05

    Practice ethically

    Only test systems you own or have explicit permission to test. Club labs and CTF platforms are the right places to experiment.
